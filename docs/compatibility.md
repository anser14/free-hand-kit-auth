# Compatibility

The initial candidate support range is Python 3.10–3.13, Django 4.2–6.0, DRF 3.14–3.16,
DRF SimpleJWT 5.x, and drf-spectacular 0.28.x or later before its next major version.

These are packaging candidates, not verified public support promises. CI must validate
each published combination using SQLite plus PostgreSQL release integration tests,
default and custom user models, and a clean wheel/sdist installation before a stable
release claims support.
